# Le Chemin du Savoir 🦉

Un jeu d'énigmes de lettres et de chiffres, pensé pour les amateurs de Scrabble, de *Des chiffres et des lettres* et de casse-têtes.

Guidé par Glaux, la chouette d'Athéna, le joueur voyage de cité en cité à travers cinq routes : la Côte des Sages, la Route des Sables, la Vallée des Lumières, les Monts de Fer et les Hautes Terres. Dans chaque cité, un savant l'attend avec une épreuve : mot le plus long, compte est bon, lien caché, suite logique, intrus, frise du temps, message codé… Chaque étape réussie ajoute un fragment de savoir au carnet.

## Jouer

Le jeu tient dans un seul fichier, `index.html`. Il fonctionne sur téléphone, tablette et ordinateur, sans installation ni inscription.

## Publier avec GitHub Pages

1. Déposer `index.html` à la racine du dépôt.
2. Dans le dépôt : **Settings → Pages**.
3. Sous **Build and deployment**, choisir **Deploy from a branch**, la branche `main` et le dossier `/ (root)`, puis **Save**.
4. Après une minute, le jeu est en ligne à l'adresse `https://<votre-nom>.github.io/<nom-du-depot>/`.

## Sauvegarde

La progression est enregistrée automatiquement dans le navigateur du joueur. Elle reste disponible tant qu'on joue sur le même appareil, avec le même navigateur, et qu'on n'efface pas ses données de navigation.
